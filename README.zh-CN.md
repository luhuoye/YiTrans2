# 凉山彝语翻译 (YiTrans)
彝文(规范彝文/凉山) ⇄ 普通话 词句库检索 + 内置彝文键盘 + 收藏 + 做题。

## 打包 APK（GitHub）
1. 新建 **私有** 仓库，把本目录全部文件推送到 main 分支。
2. 打开仓库 Actions → Build APK（推送后自动运行，也可手动 Run workflow）。
3. 运行完成后在页面底部 Artifacts 下载 `YiTrans-apk`，解压得到 `app-debug.apk`，手机安装即可。

## 功能
- 翻译：打开即「彝文→中文」，底部自动出现内置彝文键盘（拼音候选 + 全部1165个音节字表）；「中文→彝文」用系统中文输入法。
- 字典：41个主题分类浏览 + 中文/拼音/彝文搜索；音节表（彝文字 ↔ 拼音）。
- 做题：选择题、判断题、填空题、翻译题（彝→中、中→彝，需输入答案）、混合、收藏题复习；答完显示解析，可收藏题目。
- 考试：一套试卷满分100（选择10×3 + 填空5×4 + 判断10×2 + 翻译6×5），交卷得分、分项得分、错题解析，历史成绩与最高分。
- 收藏：词句、题目。

## 说明
- 翻译为《彝语900句》942 个句子的相似度检索，不是机器翻译；词库外的内容查不到。
- 彝文显示依赖系统自带 Noto Sans Yi 字体，个别国产 ROM 如显示方块，需自行加入字体文件。
- 词库来自《彝语900句》(版权属原出版社/作者)，仓库请保持私有，公开发布前需取得授权。
- 重新生成词库：`python3 tools/build_corpus.py book.md`
